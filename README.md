# Dra. Gabrielly Braga — Site da Clínica (Guarulhos)

Site one-page responsivo, focado em conversão para WhatsApp.

## Ver o site
Abra `index.html` no navegador, ou rode:
```
cd clinica-dra-gabrielly
python3 -m http.server 8000
# acesse http://localhost:8000
```

## Personalizar (importante antes de apresentar)
1. Abra `script.js` e troque `WHATSAPP_NUMBER` pelo número real da Dra. (DDI+DDD+número).
   Todos os 15 botões atualizam sozinhos.
2. Em `index.html`, troque o endereço genérico "Guarulhos — SP" pelo endereço real.
3. Se tiver fotos reais da Dra./clínica, substitua os links Unsplash nas tags `<img>` do hero e sobre.
